E-Commerce Management System

A menu-driven E-Commerce Management System developed using Python as part of the CBSE Class XII Informatics Practices project (2026–2027).

About the Project

This project demonstrates how Python programming concepts can be applied to manage a simplified online shopping system.

Features

- Display and search products
- Add products to a shopping cart
- Manage customer details
- Calculate bills with automatic discounts
- Place and view orders
- Display sales information
- Generate data visualizations

Technologies Used

- Python 3
- Matplotlib

Python Concepts

- Lists and Dictionaries
- Functions
- Conditional Statements
- For and While Loops
- Exception Handling
- Data Visualization

Data Visualizations

- Category-wise Sales – Bar Chart
- Monthly Sales – Line Graph
- Order Value Distribution – Histogram

Project Limitations

- No permanent database storage
- No real payment gateway
- No login or authentication system
- Sample product and sales data

Installation

Install the required library:

pip install matplotlib

Run the project:

python main.py
